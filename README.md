# icuConnect – Downloads

Android-App für [Intervals.icu](https://intervals.icu): Heute, Kalender, Fitness (PMC) und Wellness im dunklen Nachtblau-Design.
Inoffizielle App, nicht von Intervals.icu.

## Installation

1. Unter **[Releases](../../releases/latest)** die Datei `icuConnect-x.y.apk` auf dem Handy herunterladen.
2. Datei öffnen. Android fragt einmalig, ob der Browser/Dateimanager Apps installieren darf → erlauben.
3. App starten und mit deiner **Athleten-ID** und deinem **API-Key** anmelden
   (Intervals.icu → Einstellungen → Developer Settings).

## Updates

Die App prüft beim Start, ob es eine neue Version gibt, und zeigt dann oben auf „Heute“ eine Karte an.
Ein Tipp auf **Herunterladen & installieren** genügt, Anmeldung und Daten bleiben erhalten.
